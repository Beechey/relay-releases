# Relay IPTV — releases

Signed Android APKs for Relay IPTV, an Xtream Codes IPTV player for Android TV.

Download the latest `relay-iptv-x.y.z.apk` from [Releases](../../releases/latest) and sideload it. Installed copies update themselves from this page.

Source code is private. This repository holds release builds only.
